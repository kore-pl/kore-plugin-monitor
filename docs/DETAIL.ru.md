# kore-plugin-monitor (плагин мониторинга системы)

## Что делает плагин

Читает реальные данные Linux /proc и /sys и по запросу возвращает обзор системы, топ процессов, использование дисков и температуры. Производственный уровень (depth_level=production), базовый компонент без зависимостей.

Методы только для чтения объявляют system:read.

## Ключевые моменты

- Без опросов (G-19): нет тикера, AfterFunc или фоновых горутин. CPU и CPU% процесса берут две пробы внутри одного запроса с time.Sleep(200ms) между ними; затем вызов возвращает результат. Точки истории добавляются только при вызове monitor.system по истечении интервала, поэтому в простое расход CPU нулевой.
- Пороговые opовещения только возвращаются: alerts[] содержит метрику, текущее значение, порог, уровень и практическую подсказку; плагин не отправляет уведомления, письма или вебхуки и не обращается к сети (G-10). Уведомления — задача центра оповещений ядра.
- Нет внешних зависимостей: только github.com/pengtang1024/kore/pkg/pluginapi и стандартная библиотека.
- Методы: monitor.system, monitor.processes, monitor.disks, monitor.temperature (полные таблицы в DETAIL.md).

## Установка и проверка

Установите `monitor` из маркетплейса плагинов или импортируйте dist/monitor-0.5.0.tar.gz, собранный через make dist. Проверка: make check (gofmt, go vet, go test -timeout 200s), включая наборы boundary и fault.
